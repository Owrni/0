Используемые технологии:

  • Web Speech API - для распознавания живого голоса через микрофон
  • HTML5 File API - для загрузки аудиофайлов
  • JavaScript (ES6+) - клиентская логика обработки

Распознавание живого голоса работает в браузере (требуется Chrome). Распознавание аудиофайлов - демо-версия.
